# Document Similarity Analyzer — Frontend

A web-based interface for the Document Similarity Analyzer, developed as part of a collaborative team project at KLH Deemed to be University.

This repository contains my individual frontend contribution to the project.

## About the Project

The Document Similarity Analyzer aims to help users compare documents and understand their textual similarity through a dedicated application interface.

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/), which includes npm.

### Clone the Repository

    git clone https://github.com/bhavanakondakrindi/KLH-CSE-2026-27-TEAM-07-DOCS_SIMILARITY-BHAVANA-.git

### Navigate to the Project

    cd KLH-CSE-2026-27-TEAM-07-DOCS_SIMILARITY-BHAVANA-

### Install Dependencies

    npm install

### Run the Application

    npm run dev

Open the local URL displayed in the terminal to view the application in your browser.

## Production Build

To create a production build:

    npm run build

To preview the production build:

    npm run preview
